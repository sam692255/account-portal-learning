\# Account Portal Learning Project



A learning project for building a web app with account signup and login.



\## Technology



\- React and TypeScript: website

\- Express and TypeScript: API

\- PostgreSQL: database

\- Docker Compose: runs the app and database together

\- Caddy: provides HTTPS on a future internet-facing server



\## Run locally on Windows



1\. Start Docker Desktop.

2\. In PowerShell, go to the folder containing this README and run:



&#x20;  ```powershell

&#x20;  docker compose up --build
